## 删除与当前职责

| 删除内容 | 当前路径与理由 |
| --- | --- |
| Runtime `takeMatchingResult` → Flow 同名方法 | 删除只有测试/基准调用的两层结果读取；已有 `CoreTestCompletion`、`BenchmarkMatchingAwait` 读取槽内既有事实，不执行资金计算或提交 |
| Runtime `completeMatching` | 纯转发删除，测试/基准直接进入 `OrderedCommitCoordinator.completeMatching`；生产有序提交及快照完成路径保持原入口 |
| 单分片 3 个便利构造器及两类管线的自动启动分支 | 只有测试需要构造时启动；统一装配后由原启动边界明确启动，不增加 worker 或异步阶段 |
| 单分片/组的默认 `start` 重载、默认 `submit` 重载 | 删除只补默认参数的调用层；CPU 配置和可空结算事件在实际调用处明确传入 |
| 单分片 `inFlight/submittedPosition` | 删除测试观察接口；窗口测试检查现有深度，批次测试在原反射观察范围检查私有游标 |
| 组 `poll` | 只有测试调用；测试回收真实传输槽后直接从原 CommandSlot 收结果，生产通知路径不变 |
| 组 `close(Runnable)` | 没有业务调用的末尾动作与重复关闭遍历删除；AutoCloseable 的 `close()` 统一使用现有 `closeShards(null)`，继续关闭所有分片并聚合异常 |
| `start` 中重复重启保护 | `worker != null` 已在前置条件返回；worker 在启动前赋值且不清空，后面的 started/startupFailure 检查不可达，删除该分支 |

保留实际线程交接、提交栅栏、槽占用/容量检查、故障通知、Lane 所有权和资金/证据验证。删除测试夹具中未使用的循环变量，合并其重复的结果选择代码。没有把生产实现改成新的层层适配框架。
