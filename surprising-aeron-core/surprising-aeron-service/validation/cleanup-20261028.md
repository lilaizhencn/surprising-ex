# Aeron 冷态测试入口清理（2026-10-28）

本轮删除 **16 个生产方法**及 **2 组空条件分支**，生产源码净减少 **165 行**。改动集中在 `TradingAccountRuntime` 和 `AccountLaneState`，没有新增生产类或接口。

## 删除与现行职责

| 删除内容 | 现行路径与测试方式 |
| --- | --- |
| Runtime `removeUser` | 没有业务命令调用；删除整用户表清理分支。实际失败回滚仍由 `RuntimeAccountRollback` 恢复用户及成员状态 |
| Runtime `removeOrder/removePosition` | 只服务测试的删除入口移除；测试在现有夹具中制造删除事实，继续使用真实 Lane 删除、索引撤销、回滚前值、变化收集和身份退休证明 |
| Lane `removeUserValue/removePositionValue/removeUserBalances/removeReservationIds/removeActiveOrderIds/removeLeverageKeys/removeUserClientOrders` | 随上述入口失去全部生产调用的原语表转发一并删除；生产结算与回滚直接管理原表 |
| Runtime `pendingTransfers(int)` | 删除冷查询列表物化；分页测试直接检查真实路由页、读取对应待转账并完成页游标 |
| Runtime `changedUsers/changedOrders/changedReservations` | 删除只为测试创建的集合副本；测试观察同包权威缓冲 |
| Runtime `laneCount`、Lane `userCount` | 删除测试观察包装；使用不可变拓扑和实际成员资格/所有权检查 |
| `putReservation/replaceOrder` 中的空条件块 | 删除没有状态变化和结果的遗留分支；实际预留替换、用户校验和变更登记保留 |

删除了测试中仅验证未提供业务入口的整用户删除尾部断言，保留成员复用与真实回滚检查。夹具中的删除事实准备不模拟资金公式，不向生产重新增加测试 API。

前两批 `f9773f56d`、`1eda62856` 已分别清理 16、23 个方法/访问器和 67 个过时文件。本文件只保留当前源码对应的验证记录，旧轮次详细内容可从 Git 查看。
