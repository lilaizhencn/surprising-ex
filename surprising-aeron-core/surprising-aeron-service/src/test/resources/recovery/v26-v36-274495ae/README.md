# 已发布恢复格式样本

来自 `274495ae` 的 `SharedProductLineSnapshotContractTest`，HotSpot JDK 27。
封套 v26、交易状态 v36、Matcher v8；覆盖六产品线的账户、冻结/撤单、衍生品标记价、资金费或交割标记及资金幂等记录。

- `.snapshot`：固定的历史二进制快照。
- `.command`：快照之前已成功入账的原始资金命令；恢复后重复提交不得二次入账。
- `.expected`：原版本状态哈希、资金哈希、经济资产合计（逐行）。

这些文件不得由当前版本测试重新生成来绕过兼容性失败。新增格式样本应另建目录，保留本目录。
