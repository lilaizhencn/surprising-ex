# 认证材料与充值入口（2026-10-07）

## 身份认证

`UserComplianceController` 新增登录用户国家目录和未提交材料删除接口。`CountryRepository` 从数据库读取 249 个 ISO 国家/地区、国旗及中英文名称；增量迁移为 `deployment/migrations/20261007-kyc-country-documents.sql`，初始 SQL 同步维护。

Web 直接展示填写表单；审核中展示等待状态；通过后只展示成功；拒绝后展示原因，点击重新认证才重新填写。身份证必须上传正面、反面及手持照，护照上传个人资料页。标准/增强等级额外要求三个月内地址证明，企业额外要求登记证明。前后端检查用户填写的到期日及地址证明日期（UTC 日历月），材料真伪和图片中的日期仍由认证服务/人工审核确认，不能把填写日期校验当成 OCR 核验。

`KycDocumentService` 校验材料类型、归属、文件签名及大小。日期保存在提交材料 JSON 引用中。删除接口仅软删除当前用户未提交材料，已提交审核证据保持不变。认证已审核中或已通过不能再次提交。外部服务的 SDK 无本地文件入口继续由服务商采集和核验证件，兼容现有移动端会话；新 Web 表单要求先上传完整材料。

测试环境必须显式启用 `GATEWAY_KYC_DOCUMENTS_ENABLED`，并配置持久化私有存储。外部认证真实生产回调不在本次测试范围；目前服务器仍为 SUMSUB 测试模拟。

## 充值

`WalletFundingService` 组合后台已上线币种、充提网络开关和 custody 租户可用网络，提供 `/api/v1/wallet/assets?operation=deposit|withdraw`。`/api/v1/wallet/deposit-address` 使用认证用户 ID 构造 custody subject，以固定 addressVersion=1 调用租户地址接口。托管服务对租户/链/subject/version 原子复用已有地址，不在交易端另建地址缓存。返回地址必须与用户、链及 ACTIVE 状态一致。

后台币种页从 `/api/v1/admin/assets/custody-chains` 联动选择网络，读取代币合约和精度。网络启用前校验 custody 是否支持该币种及充提操作。原有审计及管理鉴权保持执行。

Web 进入页面读取可充值目录，支持字母模糊查找、图标及币种/网络联动。选择后自动获取地址和生成二维码，支持复制和 PNG 下载。异步响应按登录会话/币种/网络隔离，避免切换时展示旧地址。
