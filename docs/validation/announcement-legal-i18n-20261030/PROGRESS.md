# 公告、协议与十二语种验证（2026-10-31）

## 交付范围

- 后台富文本编辑、图文/音视频上传、取消与预览，按实际完成的语言发布公告。公开媒体复用 social 的 app-public / cdn.surprising.top，限定 public/exchange/content/；不公开 C2C 或身份材料。
- 十类原创协议的十二语种正文、草稿导入、审批发布、不可变修订、历史阅读与审计。复制为新修订后可保存发布；发布替代版本要求用户重新确认，必需协议不能无替代撤回。
- Web 页脚、登录/注册、Google One Tap 与 App 个人页、登录/注册提供入口和默认未勾选的确认。服务端在创建账户/发 token 前验证具体修订及阅读语言，缺少现行必需协议不开放普通认证。
- Web 每语种 1915 条、App 每语种 3455 条完整字典：简中、繁中、英语、西语、法语、德语、巴西葡语、俄语、阿拉伯语、日语、韩语、印地语。全部缺译/占位符检查通过，未使用英文复制充数。补校了金融术语和关键法律否定语义；用户名、文件名、正文与业务标识保留来源数据。
- 运营主体和邮箱复用 social；交易域名保持 https://ex.tokdou.com。正文不是经营许可证明，生产发布前仍须由运营主体核对实际业务与适用法律，按 deployment/legal/README.md 审核发布。

- 构建后的 Web 在实际 CSP 下读取真实 R2/CDN 图片、音频和视频，桌面亮色与小屏暗色均验证媒体时间增长。相同正文的已读更新保留媒体节点，避免重置播放。
- iOS 26.5 / iPhone 16 模拟器：完整应用壳的个人页、协议中心、英语/阿拉伯语/印地语切换、英语和印地语正文、默认未勾选和勾选状态，实际点击通过。另验证真实音频及内嵌视频时钟增长、暗色、Home 后停止、返回公告中心。

## 清理与上线

本轮 27 个 QA 媒体对象键已从 R2 删除，未列举或删除其他前缀；独立 QA 数据库、临时 iOS/Android 设备以及 QA 服务已清理。私有 R2 凭据不进入代码和证据，验证结束后删除本机临时副本。项目依赖缓存保留，不清理用户正在使用的依赖。

生产必须按 [协议上线顺序](../../../deployment/legal/README.md) 应用迁移、配置公共 R2、导入并人工复核草稿、审批发布用户协议与隐私政策，再开放普通认证。现行协议尚未发布时的 503 是有意的保护条件。Cloudflare Worker 仍为 surprising-ex-web，wrangler.jsonc 身份未改，静态 CSP 只新增限定公共媒体来源。
