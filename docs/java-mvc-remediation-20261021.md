# Java 分层问题整改进度

目标：解决 `java-mvc-audit-20261021.md` 与逐文件 CSV 中确认的问题，逐一复核跨表读取例外，并以当前源码和实际验证结果关闭问题。整改范围保持完整，分批提交不代表全项目已完成。

## 业务与职责规则

- Controller 绑定并校验请求参数，处理 HTTP 响应；Service 聚合业务规则、权限场景、事务和数据访问。
- 每个 Repository 仅对应一张表；必要关联读取需明确注释目的、字段来源和事务/分页边界。
- 调度入口归 `task`，拦截组件归 `interceptor`，工具归模块内 `utils`，配置和异常按职责归包。
- 保持六产品线、资金精度、幂等、锁顺序、提交投影、线程所有权及恢复边界；不引入兼容或兜底分支。
